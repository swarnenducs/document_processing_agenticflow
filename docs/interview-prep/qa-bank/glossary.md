# GenAI interview — quick glossary

| Term | Plain English |
|---|---|
| **LLM** | Large language model (chat completions) |
| **Agent** | LLM + tools + loop that can act |
| **Tool** | Function the model can call |
| **MCP** | Protocol to expose tools to agents |
| **LangGraph** | Graph/state-machine workflows for agents |
| **LangChain** | LLM app building blocks (prompts, models, LCEL) |
| **MAF** | Microsoft Agent Framework (agent host) |
| **HITL** | Human-in-the-loop confirmation |
| **RAG** | Retrieve docs then generate (not primary here) |
| **Structured output** | Force JSON/schema from LLM |
| **Orchestrator** | Chooses which specialist/tool to call |
| **Specialist** | Domain worker (document/voice graphs) |
| **TPM** | Tokens per minute (rate limit) |
| **xid** | Correlation / request id |
| **OOXML** | Word document XML format |
| **LCEL** | LangChain Expression Language (`a \| b`) |
| **Checkpoint** | Saved graph state for resume |
| **Streamable HTTP MCP** | MCP over HTTP for services |
